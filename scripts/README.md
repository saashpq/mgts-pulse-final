# Переносимое демо для Windows

Для сборки нужны Windows, PowerShell, Git, Go 1.26 и Node.js 22 с npm. Сохраните изменения проекта в коммите. Откройте PowerShell в папке с `go.mod`. В командном репозитории это `mgts/pulse`, в отдельном репозитории проекта — его корень. Выполните

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-demo.ps1 -OutputPath .\pulse-windows-demo.zip
```

Скрипт берёт исходники из текущего коммита, устанавливает зависимости по `package-lock.json` и печатает SHA-256 готового архива. Укажите свободное имя для каждого нового архива. В комплект входят сервер, сервис анкет, интерфейс и учебные анкеты из `data/demo-*.csv` со списком учебных участников из `data/demo-survey.json`.

Для показа распакуйте ZIP в доступную для записи папку и дважды нажмите `START-DEMO.cmd`. Откройте [кабинет HR](http://127.0.0.1:8270) и [анкеты](http://127.0.0.1:8271). Каждый запуск создаёт отдельную учебную сессию. Для завершения нажмите Ctrl+C в окне запуска. Go и Node.js нужны только на компьютере сборщика.

В GitHub откройте **Actions → pulse**. Проверки запускаются при изменениях проекта и по кнопке **Run workflow**, когда этот workflow есть в основной ветке. После успешных тестов Go, интерфейса и расчётов пилота ZIP доступен в разделе **Artifacts** прогона в течение 14 дней.
