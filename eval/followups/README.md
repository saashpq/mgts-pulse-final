# Проверка сопровождения стажёров

## Что сделала модель

26 ноября 2026 года локальная Qwen2.5-7B-Instruct в формате Q4_K_M разобрала шесть вымышленных ситуаций с восьми профессиональных позиций. Для каждой комбинации создавалась отдельная беседа. Сначала модель выбирала два источника из трёх, затем по ним предлагала одно действие и способ его проверки. Эталонное действие из файла сценариев в запрос не входило. Все 48 ответов, включая неудачные, сохранены. [Сценарии и роли](scenarios.json) · [Полный результат прогона](review-2026-11-26.json)

| Проверка | Что решили для продукта |
|---|---|
| Срок прошёл, ответа нет | Показать открытый срок в очереди. Исход остаётся неизвестным. В роли стажёра модель верно предложила связаться с ним и записать ответ. |
| Шаг выполнен, участник отмечает частичный эффект | Записать оба факта, прямо выбрать дальнейший контакт или завершение. Наставник может подтвердить, что он предоставил помощь. О её пользе следует спросить самого участника. |
| Оценка выросла с 2 до 4 | Показать изменение. В роли стажёра модель предложила обратиться к «автору сценария». Такое действие для реального HR бесполезно. Основание для вывода о пользе — ответ участника. |
| Новая жалоба того же типа | Сохранить прежний контакт и начать отдельную историю нового эпизода. Так повторная жалоба остаётся видна. |
| Цитату из маленькой группы хотят показать руководителю | Оставить доступ к исходной цитате куратору. Предложение модели запросить список всех участников с оценками отклонили как избыточное. |
| Два куратора сохранили разные итоги одной встречи | Повтор одной команды безопасен. Устаревшая конфликтующая запись требует перечитать последнее состояние. Предложение модели увеличить версию после второго конфликтующего сохранения отклонили. |

Это проверка покрытия сценариев и источник гипотез для тестирования. Все роли исполняла одна модель. Эти результаты нельзя использовать как опрос HR-экспертов или как численное доказательство качества методики. Нуждающиеся в проверке предположения и порядок пилота описаны в [обзоре практик](../../docs/WORLD-PRACTICES.md).

Для воспроизведения запустите совместимый с OpenAI API локальный сервер модели в режиме JSON, затем из корня приложения выполните:

```powershell
python eval/followups/review.py --base-url http://127.0.0.1:19176/v1 --model Qwen2.5-7B-Instruct-Q4_K_M --out review-local.json
python -m unittest discover -s eval/followups -p "test_*.py"
```

## Показатели одного цикла

Отчёт обрабатывает снимок очереди HR. Ключевые доли отвечают на разные вопросы.

| Вопрос | Числитель | Знаменатель |
|---|---|---|
| Куратор вовремя зафиксировал контакт? | Записи, сделанные до конца согласованного дня по Москве | Все наступившие обязательства, в том числе открытые, с учётом переноса срока |
| В срок выяснили, помогло ли действие? | Своевременные записи с известным исходом | Тот же набор наступивших обязательств |
| Действие выполнено? | Записи с отметкой «выполнено» | Все зарегистрированные контакты |
| Участник сообщил, что помогло? | Явный ответ «помогло» | Контакты с известным исходом, включая ответы «частично» и «без улучшения» |

Отчёт показывает и количество записей с неизвестным исходом. Пустой знаменатель отображается как «нет наблюдений». Контакты одной пары могут повторяться. Дата в отчёте — дата снимка сервера. Своевременность измеряется по времени регистрации. Ответ, который HR внёс поздно, останется поздним. Если HR изменил дату до конца согласованного дня, считают новый срок. Если перенёс её уже после истечения, прежний срок также остаётся в знаменателе как пропущенный.

Пример для демонстрации на собственном компьютере. Выполните в PowerShell, пока открыт Windows-прототип; в корпоративном контуре запрос выполняет авторизованный HR. Файл снимка содержит персональную рабочую информацию, поэтому для передачи коллегам используйте только итоговый отчёт.

```powershell
$queuePath = Join-Path $env:TEMP ("pulse-" + [guid]::NewGuid() + ".json")
try {
    $queue = Invoke-RestMethod 'http://127.0.0.1:8270/api/v1/follow-ups'
    $queue | ConvertTo-Json -Depth 15 | Set-Content -Encoding UTF8 -LiteralPath $queuePath
    python eval/followups/pilot.py $queuePath
} finally {
    if (Test-Path -LiteralPath $queuePath) { Remove-Item -LiteralPath $queuePath }
}
```

Для машиночитаемого отчёта добавьте `--json`. Итог содержит только общие счётчики и дату. При пяти парах даже общую статистику перед публикацией проверяет куратор.
