# Пульс стажировки

Система для куратора стажировок МГТС. Ответы стажёра и наставника связываются по участнику и месяцу. HR видит заполненность программы, изменения оценок и исходные комментарии, затем выбирает следующую пару для разговора. Публичный пример использует вымышленные данные.

## Запуск из исходного кода на Windows

Нужны Go 1.23 или новее, Node.js 22 и npm. Команды выполняются из корня репозитория в PowerShell.

```powershell
cd frontend
npm ci
npm run build
cd ..
New-Item -ItemType Directory -Force web | Out-Null
Copy-Item frontend/dist/* web/ -Recurse -Force
go build -o pulse.exe ./cmd/server
go build -o forms-service.exe ./forms
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Основной экран доступен по адресу http://127.0.0.1:8260, две формы — http://127.0.0.1:8261. На экране «Источники данных» есть прямые ссылки на обе анкеты. При первом запуске в историю загружается учебная выборка. Последующие запуски сохраняют внесённые изменения. Закройте запуск сочетанием Ctrl+C.

## Как проверить передачу

Выберите учебную пару и период, заполните все оценки и отправьте анкету. Сервис отправит событие на HR-сервер. В карточке пары появится ответ с источником, баллами и текстом. Ещё одна отправка за тот же период уточнит запись этой стороны. Предыдущие периоды сохранятся. Техническая документация находится в файле [GUIDE.md](GUIDE.md).

## Компоненты

Go, React, TypeScript, Vite, TanStack Query, SurveyJS Form Library, Golos Text. Для модельного режима используется совместимый с OpenAI API интерфейс локального движка. На стенде финала проверяли Qwen2.5-7B-Instruct с llama.cpp. Лицензии поставляемых компонентов приведены в каталоге licenses и в пакетах npm.
